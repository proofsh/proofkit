ProofKit helps you build modern web interfaces for FileMaker while keeping your FileMaker file at the center of the app. The docs cover the recommended coding-agent workflow, the CLI, WebViewer architecture, type generation, and the lower-level packages that power the stack.

If you're new, start with Coding Agents. It walks through the v2 path from install to a deployed WebViewer app.
