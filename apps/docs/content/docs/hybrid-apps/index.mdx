A ProofKit hybrid app is a modern web interface running inside a FileMaker WebViewer. The web layer handles the UI. FileMaker still provides the data, security, scripts, file system access, printing, and deployment environment.

This section explains the model behind the getting started path. Read it when you want to know how the pieces work at runtime, how data moves, and why WebViewers are a strong on-ramp for modernizing FileMaker apps.

## The short version

Think of the WebViewer as the interface layer and FileMaker as the application platform underneath it.

- The user interacts with React UI in the WebViewer.
- The web app calls FileMaker scripts when it needs data or business logic.
- Scripts read and write the database with the user's FileMaker permissions.
- Scripts can also call external APIs, access files, generate PDFs, and use plug-ins.

Start with [Why WebViewers?](/docs/hybrid-apps/why-webviewers) for the concept, then read [Data Access](/docs/hybrid-apps/data-access) when you are designing real screens.
